# ⚡ Avraham Ovadia – Certified Electrician Website
A professional one-page business website built for a certified electrician in the central region of Israel.

🌐 Live Site:  
https://avraham-ovadia.netlify.app/

---

## 📌 Project Overview

This website was built as a modern, responsive profile site for a licensed electrician.  
It includes service presentation, customer reviews, contact form integration, and WhatsApp lead generation.

The goal was to create a clean, trustworthy business website.

---

## 🚀 Features

- ✅ Responsive design (Mobile First)
- ✅ Modern navigation bar with mobile hamburger menu
- ✅ Services section
- ✅ About section with image
- ✅ Customer reviews section
- ✅ Contact form
- ✅ Floating WhatsApp button
- ✅ SEO optimization (meta tags, sitemap, robots.txt)
- ✅ Deployed with Netlify

---

## 🛠 Technologies Used

- HTML5
- CSS3 (Flexbox & Grid)
- JavaScript (Vanilla JS)
- Font Awesome
- Netlify (Deployment)
- Git & GitHub (Version Control)

---

## 📱 Responsive Design

The website is fully responsive and optimized for:
- Desktop
- Tablet
- Mobile devices

---

## 🔍 SEO Optimization

- Meta title & description
- Structured headings (H1, H2)
- Image alt attributes
- sitemap.xml
- robots.txt
- Google Search Console integration
